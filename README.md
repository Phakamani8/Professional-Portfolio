Personal Portfolio Website

Overview

A personal portfolio website built to showcase my projects, educational background, professional summary, and personal interests. The website serves as a digital portfolio and provides visitors with an overview of my background in Information Technology.

Technologies Used

HTML5 – Structures the website content.

CSS3 – Handles styling, layouts, animations, and responsive design.

JavaScript – Adds interactive functionality, including dynamic header styling when scrolling.

Features

Home: Introduction and personal welcome section.

Portfolio: Displays featured projects in a grid layout.

Resume: Presents educational background and professional summary.

About Me: Provides information about my interests and personality.

Contact: Displays contact details and a contact form.

Interactive Navigation: The navigation header changes appearance when scrolling.
